How float rules work

Every completed request deducts from the provider's float balance. Providers without enough float will not see the matching requests in their feed.

e.g. 5 → K5 deducted from a K100 delivery

Minimum Float to See Each Request Type

Provider must have at least this much float to receive that kind of request

A provider with K4 float and a "Min float per ride" of K10 will not see any ride requests, but they will still see errands if "Min float per errand" is K5 or less.
